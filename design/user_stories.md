US01 – Registar Entrada:
Como funcionário, quero registar meu check-in para que o sistema registre o início da minha jornada de trabalho.
Critério de aceitação;
- O sistema deve identificar o funcionário antes de registar o ponto.
- O sistema deve registar a data e horário do check-in.
- O sistema não deve permitir dois check-ins consecutivos sem um check-out.
- O registro deve ficar associado ao funcionário identificado. 
US02 — Registrar saída:
Como funcionário, quero registrar meu check-out para que o sistema registre o término da minha jornada de trabalho.
Critérios de aceitação:
- O sistema deve identificar o funcionário antes de registrar o ponto.
- O sistema deve registrar a data e o horário do check-out.
- O sistema deve verificar se existe um check-in correspondente.
- O sistema deve calcular o período trabalhado a partir dos registros de entrada e saída.
US03 — Consultar horas trabalhadas:
Como funcionário, quero consultar minhas horas trabalhadas para acompanhar minha jornada de trabalho.
Critérios de aceitação:
- O sistema deve permitir consultar os registros de um determinado dia.
- O sistema deve apresentar os horários de entrada e saída.
- O sistema deve apresentar o total de horas trabalhadas.
- O sistema deve permitir consultar o histórico mensal.
US04 — Registrar justificativa:
Como funcionário, quero registrar uma justificativa para uma ocorrência no meu ponto para que o RH possa analisá-la.
Critérios de aceitação:
- O funcionário deve informar a data da ocorrência.
- O funcionário deve informar o motivo da justificativa.
- O sistema deve associar a justificativa ao funcionário.
- A justificativa deve ficar disponível para análise do RH.
US05 — Consultar registros dos funcionários:
Como RH, quero consultar os registros de ponto dos funcionários para acompanhar suas jornadas de trabalho.
Critérios de aceitação:
- O sistema deve permitir selecionar um funcionário.
- O sistema deve apresentar os registros de entrada e saída.
- O sistema deve apresentar o total de horas trabalhadas.
- O sistema deve permitir consultar os registros por período.
US06 — Analisar justificativas:
Como RH, quero analisar as justificativas dos funcionários para decidir se elas devem ser aceitas ou rejeitadas.
Critérios de aceitação:
- O sistema deve apresentar as justificativas pendentes.
- O sistema deve apresentar o funcionário e a data relacionados à justificativa.
- O RH deve poder aceitar uma justificativa.
- O RH deve poder rejeitar uma justificativa.
- O sistema deve registrar o resultado da análise.
