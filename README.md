# Descrição do problema
O projeto consiste no desenvolvimento de um sistema de controle de ponto de funcionários, com funcionalidades relacionadas ao registro de entradas e saídas, à consulta de informações e ao gerenciamento de justificativas de ocorrências.

# Objetivos
Desenvolver um sistema organizado em classes, responsável por representar funcionários, registros de ponto, justificativas e relatórios, permitindo estruturar as operações relacionadas ao controle de jornada.

# Motivação
A escolha do tema está relacionada à necessidade de organizar e facilitar o acompanhamento dos registros de jornada dos funcionários. A proposta permite aplicar os conceitos de programação orientada a objetos, modelagem de classes e organização de sistemas estudados na disciplina.

# Estrutura do projeto
- `include/`: arquivos de cabeçalho das classes.
- `src/`: arquivos de implementação.
- `tests/`: arquivos de testes.
